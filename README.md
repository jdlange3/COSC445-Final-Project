# COSC445-Final-Project
# Project Title: Analyzing the Development Lifecycle of Vichan

## Objective and Approach
The primary goal of this project is to mine and analyze the repository metadata of Vichan, a mid-sized, open-source image board engine. The project is worth investigating as the project has stopped development and it would be interesting to look at the history. We want to accomplish data retrieval in order to build a timeline of the project with context.

## Expected Data Source
**Repository:** [https://github.com/vichan-devel/vichan](https://github.com/vichan-devel/vichan)

We plan to extract the commit history of the repo by using a script to look at the timeline of the project.
